# Качалка

Нативное приложение для Windows: фильмы, сериалы и игры для Windows в одном каталоге, поиск раздач и общая очередь torrent- и magnet-загрузок. Интерфейс на WPF, без Electron и встроенного браузера.

**[Скачать последнюю опубликованную версию](https://github.com/peregond/ka4alka/releases/latest)** · [Скриншоты](distribution/README.md) · [Новости](https://t.me/ka4alkacc) · [Чат поддержки](https://t.me/+6sT2ocaKvLxlNmRi)

## Фильмы и сериалы

Каталог с постерами, горизонтальными баннерами, описаниями, оценками и участниками при наличии данных. Общий поиск находит фильмы и сериалы по русским, английским и альтернативным названиям; результаты можно ограничить одним разделом.

- Подборки популярных и новых произведений, фильтры жанра, страны, рейтинга, года и качества.
- Рекомендации учитывают найденные варианты загрузки. Доступность участников конкретной раздачи проверяется отдельно.
- Выбор сезона и серии, фильтры по студии и типу озвучки, субтитрам и источнику.
- Качество отмечено на постере: HD Ready, Full HD, 4K или «Экранка». Плохое качество скрыто по умолчанию.
- Общее «Сохранённое», скрытие отдельных названий и жанров с восстановлением в настройках.

## Игры для Windows · новое в 0.42.0

Отдельный раздел с популярными играми и новинками Steam, поиском и страницами каталога. В карточке — обложка, описание, разработчик, издатель и минимальные системные требования. Для каталога не нужны аккаунт Steam или API-ключ.

Раздачи ищутся в RuTor, RuTracker через Knaben и настроенных PC-индексаторах Torznab. Известные консольные и Mac/Linux-издания, другие части и отдельные обновления отсекаются. Игры сохраняются вместе с фильмами и сериалами и скачиваются в общей очереди. Из очереди можно вернуться в карточку игры.

Кнопки Steam и SteamDB открывают соответствующие страницы. SteamDB не используется для автоматического сбора данных; IGDB не подключён. Скачивание игры не запускает её установщик автоматически.

## Загрузки и устройства

Компактная очередь с обложками, прогрессом, скоростью и участниками. Доступны пауза и продолжение, общее управление загрузкой и отдачей, лимиты скорости, сортировка и подробный список файлов. «Удалить из загрузок» сохраняет файлы; «Удалить файлы» удаляет их отдельно.

При первом запуске приложение предлагает выбрать папку и создаёт в ней `Ka4alka`. Очередь и настройки сохраняются в `%LOCALAPPDATA%/Kachalka`. Есть диагностика проблем загрузки, сбор логов, уведомления, контроль свободного места и восстановление соединений после обрыва сети.

Раздачу можно отправить на другой компьютер в домашней IPv4-сети. Включите «Устройства в сети» на обоих компьютерах, найдите устройство автоматически или по адресу и подтвердите одинаковый код. Получатель использует собственную папку и лимиты; доверие можно отозвать. Передача задания защищена TLS, аккаунт не нужен. Для связи может понадобиться разрешение брандмауэра в частной сети.

## Интерфейс и производительность

Тёмная тема включена по умолчанию; светлая выбирается в настройках. Окно адаптируется к размеру и масштабированию Windows. Поиск остаётся доступен в карточках и загрузках.

Карточки виртуализированы, изображения загружаются возле видимой области и сохраняются в ограниченном кэше. Запросы отменяются при уходе со страницы; одинаковые запросы объединяются. Метаданные и раздачи появляются по мере готовности, без ожидания всех источников. Лёгкий режим ограничивает фоновую работу и память и отключает декоративные анимации; его можно выбрать вручную.

## Установка и обновления

Скачайте `.exe` из [последнего релиза](https://github.com/peregond/ka4alka/releases/latest) и запустите установщик. Приложение предназначено для Windows x64. Номер версии указан в настройках; там же доступны автозапуск, проверка обновлений и перезапуск для установки.

Обновления приходят с GitHub. Загружаются изменившиеся компоненты, подпись и SHA-256 проверяются до установки; при неудачном запуске предусмотрен откат. Настройки, очередь и скачанные файлы сохраняются. Автоматическую проверку и установку можно отключить.

## Источники и ограничения

Метаданные фильмов и сериалов поступают из каталога «Ка4алка Онл@йн», Zona, TMDB и TheTVDB по доступности; игровой каталог — из Steam. Для поиска раздач используются публичные источники, в том числе RuTor, NNM-Club, MegaPeer, BigFanGroup, RuTracker через Knaben, Internet Archive, EZTV и Nyaa по применимости. Сайт и его копии помогают при недоступности прямых источников.

Наличие карточки не гарантирует наличие подходящей раздачи или активных участников. Источники могут ограничивать доступ по региону или менять формат ответа. Отсутствующие оценки, озвучка и требования не заменяются вымышленными значениями. Используйте приложение для материалов, которые вы вправе скачивать и распространять.

## Разработка

Исходники приложения — в `native/`, сайта — в `web-index/`, локальной сети — в `lan-core/`, обновлятора — в `update-core/` и `updater/`. Нужны Windows и .NET 10 SDK для запуска WPF; серверная часть использует Node.js и lockfile npm.

```powershell
./build.ps1 -Test
dotnet run --project lan-tests/Kachalka.LanTests.csproj -c Release
dotnet run --project update-tests/Kachalka.UpdateTests.csproj -c Release
```

Windows CI проверяет установщик, сохранение настроек, подписанное обновление и настоящий WPF-интерфейс. Проверки игр и отзывчивости выполняются также с ограничением .NET до двух и четырёх процессоров. Это проверка конкретных сценариев, а не обещание одинаковой скорости на любом компьютере.
