# Качалка — лендинг

Исходники существующего лендинга ka4alka.cc с обновлённым прозрачным знаком @.

`npm ci`, `npm run build`, `PORT=8080 HOSTNAME=0.0.0.0 npm start`. Dockerfile сохраняет Next.js 16.4.0, standalone, порт 8080 и маршрут /health. Railway сервис web использует эту папку.

Тексты, дизайн, реальные скриншоты приложения и ссылки скачивания сохранены. Установщик и ZIP загружаются из актуального официального релиза GitHub. Каталог, его API, базы и секреты находятся в отдельных сервисах и сюда не входят.
