Обновить существующий опубликованный сайт Ка4алка Онл@йн
https://ka4alka-online-new.peregon.chatgpt.site/

Исходники: коммит 5d36ad4, ветка codex/tmdb-backdrops репозитория peregond/ka4alka.
Исходники сайта расположены в корне архива.

Добавлены /api/backdrop и /api/backdrop-image. Сохранить существующую базу D1 и привязку DB. Не создавать новый сайт или новую базу. Метаданные .openai старого проекта исключены специально: использовать привязку текущего опубликованного проекта.

На сервере сайта требуется секрет TMDB_READ_TOKEN (TMDB API Read Access Token). Вводить значение только в защищённых настройках сервера сайта. Секрет Codex не переносится в сайт автоматически; его прокси-подстановку нельзя публиковать вместо настоящего значения.

Установить зависимости по package-lock.json, проверить TypeScript, собрать и опубликовать сайт. Проверить /api/backdrop?id=movies:obekt-prestupleniya и соответствующий /api/backdrop-image?file=<путь изображения>: JSON с source=TMDB и горизонтальный JPEG, без ключа в ответах. Проверить также одну карточку сериала из /api/catalog?section=series.

В Codex проверены настоящее API, поиск по IMDb и названию с годом, фон 1280×720 для Дюны: Часть вторая и Дома Дракона; серверные маршруты с настоящими карточками стартового каталога и реальным API (отсутствие D1 моделировалось). Windows-проверки коммита 5d36ad4 успешно выполнены в GitHub Actions 37996488992 и 37996488996. Новый релиз приложения пока не опубликован.
