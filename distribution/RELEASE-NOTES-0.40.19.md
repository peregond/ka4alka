# Качалка 0.40.19

Чтение локального индекса, обработка сетевых ответов каталога и поиск раздач перенесены с потока интерфейса в фон. Окно может обрабатывать ввод, пока источники загружаются или разбирают ответ; пустые подборки показывают существующие каркасы карточек. При ручном обновлении текущего каталога видимые карточки остаются на месте и слегка приглушаются до получения результата.

Локальный поиск использует заранее подготовленные слова названий вместо повторной нормализации всего каталога для каждой карточки. Сохранение индекса также сериализуется в фоне. Сохранённые записи восстанавливаются после показа окна; поиск ожидает завершения восстановления, чтобы не терять локальные результаты.

Поиск раздач запускается по уже известному названию без ожидания описания и актёров, которое раньше могло занимать до восьми секунд. Если известен только русский заголовок, англоязычные источники отдельно ожидают оригинальное название; это не задерживает русские источники. Источники работают параллельно и показывают первые доступные результаты до завершения остальных. Время ответа самих сайтов зависит от сети и их доступности.

Сохранены новый логотип 0.40.18, настройки, очередь загрузок и проверка подписанных обновлений. Добавлена Windows-проверка обработки ввода во время загрузки каталога и поиска раздач, восстановления индекса и совпадения результатов ускоренного локального поиска с предыдущим алгоритмом.
