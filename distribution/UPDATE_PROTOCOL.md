# Подготовка обновлений «Качалки»

Постоянный адрес метаданных:

`https://github.com/peregond/kachalka-releases/releases/latest/download/latest.json`

Архив для ручной установки:

`https://github.com/peregond/kachalka-releases/releases/latest/download/Kachalka-win-x64.zip`

Архив каждого выпуска имеет собственный адрес с тегом версии. `latest.json` ссылается на этот адрес, поэтому скачивание не перепутает версии при появлении нового выпуска.

## Формат 1

- `schemaVersion`: 1.
- `appId`: `kachalka`.
- `channel`: `stable`.
- `version`: трёхкомпонентная версия приложения, например `0.18.0`.
- `platform`: `win-x64`.
- `minimumWindows`: `10`.
- `package.url`: HTTPS-адрес архива конкретного выпуска.
- `package.fileName`: `Kachalka-win-x64.zip`.
- `package.size`: размер в байтах.
- `package.sha256`: SHA-256 всего архива, 64 шестнадцатеричных символа.
- `package.format`: `portable-zip`.
- `releaseNotesUrl`: публичная страница выпуска.
- `automaticInstallationAvailable`: false для выпуска 0.18.

Метаданные и контрольная сумма готовы для распространения. В клиенте 0.18 нет обращения к этому адресу и нет фоновой установки.

## Следующий этап в приложении

1. Проверять версию в фоне с ограниченным тайм-аутом; отсутствие сети не должно мешать каталогу и загрузкам. Добавить ручную кнопку проверки в настройках.
2. Сообщать о новой версии и показывать её изменения. Дать пользователю настройку автоматического скачивания.
3. До включения автоматической установки добавить подпись метаданных и встроенный публичный ключ проверки. SHA-256 обнаруживает повреждение файла, но сам по себе не удостоверяет издателя.
4. Скачивать архив во временную папку, проверять подпись метаданных, размер и хеш. Ограничивать допустимые адреса, объём загрузки и содержимое архива; запрещать выход путей распаковки за папку назначения.
5. Применять обновление после закрытия приложения, предварительно сохранив очередь и остановив движок. Проверять новую установку, сохранять предыдущую до успешного запуска и восстанавливать её при ошибке.
6. Сохранять настройки, очередь и скачанные файлы вне папки приложения. Не обновляться посреди передачи без контролируемой остановки.

Проверки будущего обновления: версия уже актуальна, сеть недоступна, повреждённый архив, неверная подпись, отмена, заблокированный файл, каталог без права записи, неудачный новый запуск и восстановление предыдущей версии.
