# Качалка 0.19.0

- EXE-установщик для Windows 10/11 x64: установка для текущего пользователя без прав администратора, ярлыки в меню «Пуск» и на рабочем столе, удаление через настройки Windows.
- Полная версия приложения показывается в разделе «Настройки → Качалка».
- Фоновая проверка обновлений на GitHub при запуске, автоматическое скачивание и установка при выходе. Эти настройки можно отключить.
- Кнопки проверки обновлений, просмотра изменений и «Обновить и перезапустить» в настройках.
- Подпись описания выпуска, SHA-256 и размер архива проверяются до установки; ZIP проверяется на опасные пути и неверную версию.
- Очередь сохраняется и движок останавливается перед установкой. Неудачный запуск новой версии вызывает откат. Предыдущая папка приложения сохраняется рядом с установленной версией.

Для перехода с 0.18 один раз установите `Kachalka-Setup-0.19.0.exe`: в старой версии нет механизма автообновлений. Новые версии доставляются из `peregond/ka4alka`. Для этого релиз должен содержать ZIP, `latest.json` и его подпись `latest.sig`.

Настройки и очередь сохраняются в `%LOCALAPPDATA%/Kachalka`, загруженные файлы — в выбранной папке. Установщик и обновление не изменяют их. Перед ручной установкой или удалением закройте приложение. Для переносной версии храните папку загрузок вне папки приложения.
