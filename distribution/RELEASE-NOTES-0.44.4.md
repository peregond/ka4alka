# Качалка 0.44.4 — обновлённый интерфейс Mac

Версия для Mac переработана целиком и по структуре страниц стала ближе к Windows, оставаясь в стилистике macOS: единые отступы, размеры, радиусы и шрифты, адаптивные цвета для светлой и тёмной темы, оформление Liquid Glass на macOS 26 и новее с запасным вариантом для macOS 14 и 15.

Каталог, баннеры, карточки и «Сохранённое» показывают рейтинги Кинопоиска и IMDb, жанры и страну. Добавлены фильтры по качеству и стране, полки Featured с новостями и наградами по годам, страница игр с вертикальными обложками. Карточка фильма показывает оригинальное название, жанры, разрешения, озвучку и качество раздач. Загрузки получили сводные плитки, сортировку, диагностику причин остановки, список файлов раздачи и число активных загрузок на значке Dock.

Исправлены ошибки: очередь загрузок не пропадает при неполных данных, состояние страниц не залипает при быстрой смене разделов, движок автоматически перезапускается после сбоя, обложки загружаются быстрее и не повторяют неудачные запросы. В настройках появились выбор темы, проверка уведомлений и понятные ошибки обновления с возвратом прежней версии. Добавлены сочетания клавиш для разделов, поддержка VoiceOver, увеличенного текста, режимов «Уменьшить движение» и «Уменьшить прозрачность».

Сохранены правила озвучки и единое меню «Озвучка» из 0.44.3. Выпуск содержит Windows x64, Mac Apple Silicon и Intel с единым номером версии; обновление проверяется с 0.44.3.
