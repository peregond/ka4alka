# Качалка 0.45.3 — новый баннер на Windows

- **Баннер каталога на Windows** теперь выглядит как на Mac: на всю ширину окна, с затемнением, значком-искрой, крупным заголовком, оценками, белой кнопкой «Подробнее» и круглым сердцем; стрелки по бокам, точки внизу.
- **Баннер листается сам:** каждые 8 секунд, пока он на экране, окно активно и на него не наведена мышь и нет фокуса клавиатуры. Справа от точек есть кнопка паузы. Если в Windows отключены эффекты анимации или включён облегчённый режим, баннер листается только вручную.
- У игр на баннере остаётся строка со студией.

Выпуск содержит Windows x64, Mac Apple Silicon и Intel с единым номером версии; обновление проверяется с 0.45.2.
