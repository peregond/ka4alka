# Качалка 0.43.3

- Постеры фильмов, сериалов и игр заполняют сетку через общую ограниченную очередь. Готовые изображения применяются максимум по два за проход, в облегчённом режиме — по одному. Очередь уступает обработке ввода и отрисовке.
- Проверки видимости постеров объединены; обновление одной карточки в подборке сохраняет соседние элементы. Плейсхолдеры резервируют высоту настоящих карточек и остаются статичными при загрузке.
- На обложках при наведении или фокусе с клавиатуры появляются сердечко и перечёркнутый глаз. Сердечко сохраняет название без открытия карточки и отмечается розовой заливкой; повторное нажатие убирает сохранение.
- Перечёркнутый глаз скрывает название из ленты. Вернуть его можно в **Настройки → Игнорируемое**; поиск, сохранённое и загрузки остаются доступны.
- Поведение проверено на Windows с ограничением до 2 и 4 процессоров, в светлой и тёмной темах: сетка сохраняет размеры после прихода постеров, соседние карточки не пересоздаются, выбранные сохранения и скрытия переживают перезапуск.

Автономный EXE использует уменьшенное сжатие LZMA. Автообновление сравнивает компоненты и повторно использует неизменившиеся файлы.
