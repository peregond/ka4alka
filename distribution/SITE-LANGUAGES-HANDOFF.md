# Русский, английский и испанский на сайте

Ветка: `claude/quirky-hopper-1vlmj6`. Готовые словари: `web-index/lib/locales/{ru,en,es}.json`. Переведены интерфейс каталога и все публичные тексты лендинга ka4alka.cc, включая установку, SmartScreen и FAQ.

`SiteLanguageProvider` и `LanguageSwitcher` находятся в `web-index/components/site-language.tsx`, стили — в соседнем `site-language.css`. Автоматический выбор учитывает `navigator.languages` по порядку; `ru-*`, `en-*`, `es-*` поддерживаются, для остальных используется английский. Ручной выбор сохраняется под `ka4alka.site-language`; «Автоматически» удаляет переопределение. Хранилище может быть недоступно: переключение всё равно работает в текущей вкладке. Смена языка браузера и синхронизация выбора между вкладками поддерживаются. Гидратация начинается с одинакового русского состояния на сервере и клиенте, затем применяется язык браузера.

## Сохранить опубликованный лендинг

В GitHub `app/page.tsx` сейчас открывает каталог. Это **не исходник опубликованного лендинга ka4alka.cc**. Не заменять действующий лендинг этой страницей. Сначала сохранить его актуальные исходники в GitHub; затем подключить готовые общие файлы к существующему дизайну.

Запрос для чата существующего Sites-проекта:

```text

Сохрани действующий лендинг, каталог, D1/DB, секреты, домены, дизайн и URL скачивания. Не заменяй лендинг страницей каталога из GitHub app/page.tsx. Сначала сохрани исходники действующего лендинга в эту ветку, чтобы дальнейшие обновления их не теряли. Main не меняй, PR не создавай.

Перенеси lib/site-language.ts, lib/locales/{ru,en,es}.json, components/site-language.{tsx,css}, tests/site-language.mjs из web-index/. Оберни содержимое существующего layout в SiteLanguageProvider. Добавь LanguageSwitcher справа в верхнее меню, оставив его доступным на мобильном экране и с клавиатуры.

В текущей странице лендинга используй useSiteLanguage().t для всех текстов, aria-label, alt, FAQ, установки, уведомлений об ошибках и динамических подписей версии/размера. Ключи словаря — исходные русские тексты. Для динамических значений используй шаблоны с параметрами; не переводи имена файлов, URL, названия произведений или обозначения HD/4K. Язык выбирается по navigator.languages, ручной выбор сохраняется; есть режим «Автоматически». Проверь es-ES/es-MX, en-US/en-GB, ru-RU, неподдерживаемый язык, сохранённый выбор, закрытое хранилище, повторное открытие страницы, узкий экран и клавиатуру. Смена языка не должна сбрасывать поиск и открытые карточки.

Выполни node tests/site-language.mjs, существующие обязательные тесты, tsc --noEmit и сборку. Сохрани итоговые исходники в указанной ветке и опубликуй существующий сайт. Отчитайся о реальных проверках. Для Railway подготовь тот же исходник лендинга; не заменяй его каталогом и не меняй серверные секреты.
```

После публикации сохранить фактический исходник лендинга и проверить отдельно Sites и ka4alka.cc. Тексты описаний фильмов и сериалов приходят от каталога: интерфейс переводится локально, содержимое источников автоматически не переводится.
