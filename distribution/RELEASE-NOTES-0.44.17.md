# Качалка 0.44.17

- Единый поиск фильмов, сериалов и игр на Windows и macOS. Тип результата можно отфильтровать после поиска. Недоступность одного источника не скрывает остальные результаты.
- На Mac поиск расположен по центру нативной панели окна и использует NSSearchField. Отдельный переключатель «Кино и сериалы / Игры» убран.
- Для карточек из IMDb, включая Backrooms, работают ссылки «Поделиться» и загрузка широкого фона через серверный API. В русском интерфейсе Backrooms отображается как «Закулисье реальности».
- Кнопка установки обновления на Mac сокращена до «Обновить».
