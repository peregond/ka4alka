# Качалка 0.22.0

- Обновления скачивают только изменившиеся или отсутствующие компоненты. Неизменившиеся файлы проверяются по SHA-256 и берутся из установленной версии.
- В настройках отображаются объём скачивания и число компонентов, которые не нужно загружать.
- Перед установкой проверяются подпись описания выпуска и хеши всех файлов. При ошибке запуска восстанавливается предыдущая версия; настройки и очередь сохраняются.
- Если сервер не поддерживает загрузку частей архива, приложение скачает полный пакет.

Переход с 0.21.1 и более ранних версий один раз скачает полный пакет: старый механизм ещё не поддерживает компоненты. После установки 0.22.0 следующие обновления используют новый механизм. Объём зависит от изменившихся файлов: обновление больших библиотек или среды .NET может потребовать значительной загрузки. Это обновление по файлам, а не бинарные патчи внутри файла.

Первичная установка: `Kachalka-Setup-0.22.0.exe`. Обновление установленного приложения: «Настройки → Проверить обновления».
