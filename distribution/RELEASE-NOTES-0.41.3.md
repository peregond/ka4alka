# Качалка 0.41.3

- Доработан существующий «Лёгкий режим»: ограничена фоновая обработка изображений и фильмографий, уменьшен кэш в памяти, отключены декоративные анимации. На компьютерах с двумя процессорами или доступной памятью до 4 ГБ он выбирается автоматически, если пользователь ещё не сделал ручной выбор.
- Обложки сохраняются на диск в уменьшенном размере. Повторный запуск использует миниатюры; повреждённая миниатюра восстанавливается из исходника без скачивания. При первой загрузке изображение декодируется один раз.
- Одинаковые обложки и рейтинги объединяют запросы. Изображения вдали от экрана освобождаются; уход последнего заинтересованного элемента отменяет загрузку.
- Результаты фильмов и сериалов появляются по мере ответа. Последующие объединение и сортировка выполняются в фоне. Старый поисковый запрос не может добавить поздние результаты после отмены.
- Чтение и сохранение кэша раздач, а также разбор ответов API для проверки качества перенесены из потока интерфейса. Незавершённые запросы карточки отменяются при уходе со страницы.
- Фотографии актёров также имеют ограничение памяти; сохраняются отдельная очередь открытой карточки и постепенное получение раздач из независимых источников.

Проверены реальные WPF-сценарии на Windows с ограничением .NET до двух и четырёх процессоров: ввод во время загрузки, видимые/скрытые постеры, переработка карточек, дисковый кэш и биографии. Это не эмуляция частоты CPU или ОЗУ физического ноутбука и не обещание ускорить удалённые сайты в фиксированное число раз.

Подробности: [ограничения ресурсов и проверки](PERFORMANCE-LOW-END.md).
