# Качалка 0.25.0

- Действия удаления доступны прямо в строке загрузки: серое «Удалить из загрузок» сохраняет файлы, красное «Удалить файлы» удаляет скачанные и частичные файлы после подтверждения. Они больше не спрятаны в меню с тремя точками.
- Запуск и пауза загрузки оформлены текстовой кнопкой. Подробности и открытие папки остаются компактными иконками с подсказками.
- Главное название в очереди — название фильма или сериала из каталога. Исходное название торрент-раздачи отображается отдельной небольшой строкой, чтобы видеть качество, перевод и другие детали.
- Исправлено отображение обложок в очереди. Название и обложка сохраняются при добавлении из карточки; для прежних задач восстанавливаются по достоверному совпадению с каталогом. Если соответствие неоднозначно или обложка недоступна, приложение сохраняет исходное название или показывает нейтральную заглушку.
- Поиск раздач на карточке фильма или сериала показывает состояние внутри раздела «Раздачи», рядом с результатами. Заголовок «Варианты загрузки» заменён на «Раздачи».
- Очередь, папки загрузок и настройки сохраняются при обновлении. Неизменившиеся служебные компоненты повторно используются без скачивания.

Обновление через «Настройки → Проверить обновления» или кнопку «Обновить» после фоновой загрузки. С 0.22.0 скачиваются только изменившиеся компоненты. Новая установка: `Kachalka-Setup-0.25.0.exe`.
