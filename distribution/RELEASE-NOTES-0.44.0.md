# Качалка 0.44.0 — Windows и Mac

Качалка получила нативную версию для macOS. Windows сохраняет WPF, Mac использует SwiftUI и AppKit. Общий движок отвечает за каталог, подборки, поиск, источники раздач и загрузки; новые версии выходят одновременно для Windows, Apple Silicon и Intel Mac.

- На Mac доступны фильмы, сериалы, игровые подборки Steam, общий поиск на русском и английском, страницы участников, награды, сохранение и скрытие названий и жанров.
- Общие источники и рекомендации раздач, приоритет языка интерфейса, фильтры студий, озвучки, сезона, серии, качества и источника.
- Общая очередь torrent/magnet, файлы и серии, пауза и продолжение, управление отдачей и скоростью, диагностика, контроль свободного места и восстановление после обрыва сети. Удалённые вне приложения файлы требуют явного согласия на повторное скачивание.
- Отправка загрузок между подтверждёнными Windows- и Mac-компьютерами в одной локальной сети.
- Первый запуск предлагает папку и создаёт внутри `Ka4alka`. По умолчанию включена тёмная тема; доступны светлая тема, облегчённый режим, уведомления, автозапуск, логи и поддержка в Telegram.
- На Mac изображения загружаются и уменьшаются в фоне, запросы для невидимых карточек отменяются, память кэша ограничена. Изменения очереди не перерисовывают каталог.
- Обновления Mac подписаны и скачивают изменившиеся компоненты. Установка проверяет файлы и подпись приложения, сохраняет очередь и возвращает предыдущую версию, если новая не запускается. Формат обновлений Windows сохранён.

Один релиз содержит установщик и ZIP для Windows, а также отдельные DMG и ZIP для Apple Silicon и Intel. Публикация блокируется, если обязательные проверки любой платформы не прошли.

**Требования:** Windows 10/11 x64; macOS 14 или новее. .NET включён в пакеты. Игровой раздел сохраняет каталог игр для Windows: на Mac можно скачать файлы или передать загрузку на ПК, но Windows-игры не запускаются автоматически.

**Установка Mac:** открой DMG и перетащи Ka4alka в Applications. В этом выпуске применяется ad-hoc подпись; нотариализация Apple не настроена. macOS может потребовать разрешить запуск в «Системные настройки → Конфиденциальность и безопасность».

Личные настройки, сохранённое и очередь разных компьютеров автоматически не синхронизируются. Одновременно выпускаются именно функции и обновления приложений.
