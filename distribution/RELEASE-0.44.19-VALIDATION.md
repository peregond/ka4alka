# Проверка опубликованной 0.44.19

Опубликована 22 октября 2026 года: https://github.com/peregond/ka4alka/releases/tag/v0.44.19

Исходный коммит приложения: `1c02e4a8df22d809f9b952119904d4282f625594`.

## Функциональность

- Кнопка «Другие части» раскрывает коллекцию внутри карточки после актёров. Текущий фильм исключён, остальные упорядочены по выходу. До нажатия запрос не выполняется.
- Встроенные публичные данные TMDB проверены для Star Wars (9 фильмов), Harry Potter (8) и Avatar (5, включая анонсированные части). Другие коллекции требуют серверного `/api/franchise`.
- Живой TMDB подтвердил коллекцию Harry Potter `1241` и восемь IMDb-идентичностей. Сопоставление не использует приблизительное совпадение названий; оценки TMDB не выдаются за IMDb.
- Лучшие работы участника сначала занимают один адаптивный ряд. «Ещё» раскрывает список внутри страницы; во время загрузки используются заглушки каталога. У открываемых английских карточек коллекции отдельно догружаются полные актёрские данные.
- Полная озвучка Solar Opposites от Сыендука не подтверждена. В ответах RuTor, NNM-Club, MegaPeer и RuTracker через Knaben такой студии не найдено; найденный публичный материал относится к тизеру. Непроверенная озвучка и раздача не добавлялись.

## Проверки

- Релиз: https://github.com/peregond/ka4alka/actions/runs/39832401471 . Первая попытка Windows остановилась на 60-секундном тайм-ауте публичного каталога; Linux — на нестабильном счётчике параллельного теста. Во второй попытке Windows, Mac Apple Silicon/Intel, общее ядро Linux/Windows и `mac-assets` успешно завершились. Подготовка запускалась с `publish=false`; публикация выполнена отдельно после всех проверок.
- Перед публикацией скачаны 15 файлов черновика. Неизменённый `scripts/verify-platform-release.py` подтвердил точный исходный коммит и шесть обязательных платформенных задач; `release-tools --verify-mac` — обе архитектуры Mac; `update-tests --verify-release` — подпись Windows, размер, SHA-256, пути, версию и 427 компонентов. Все 14 записей SHA256SUMS совпали. Удалены 53 временных снимка, предназначенных только для просмотра черновика.
- После публикации все 15 файлов скачаны заново без авторизации. Публичные файлы побайтно совпали с проверенным черновиком; `releases/latest/download/latest.json` и `macos-latest.json` указывают на 0.44.19. Платформенная проверка тега, обе подписи и содержимое архивов повторно прошли. `platform-validation.json` содержит исходный коммит выше и runId `39832401471`.
- macOS 27: https://github.com/peregond/ka4alka/actions/runs/39832406055 — 559 проверок, 0 ошибок, 0 предупреждений. Проверены настоящие окна в русском/английском интерфейсе, светлой/тёмной теме и при разных размерах.
- Windows с 2 и 4 ядрами: https://github.com/peregond/ka4alka/actions/runs/39832290242 — обе задачи успешны. Отчёт `franchise/render/checks.json` подтверждает загрузку только по нажатию, семь других частей Harry Potter, исключение текущей, сохранение страницы и сворачивание.
- Локально прошли desktop-core, сборки Windows и desktop-host, тесты movie-franchise, title-lookup, title-identity, TypeScript и сборка сайта. Windows сохраняет существующие nullable-предупреждения FeaturedPortal и GamesSmoke.
- Счётчики теста альтернативных названий отдельно исправлены на атомарные операции и детерминированный барьер. Локальный тест подтвердил четыре результата, четыре запроса и максимум два одновременно. Эта правка теста не меняет опубликованные исполняемые файлы.

## Зависимость от сайта

Sites сообщил о публикации версии 14 из `f826294`. Серверные файлы франшиз совпадают с исходным коммитом приложения выше. Независимая публичная проверка `/api/health` вернула HTTP 200, `status=ok`. Оба запроса `/api/franchise?imdb=tt0241527&language=ru` и `language=en` вернули HTTP 200, `id=tt0241527`, `item.id=1241` и восемь уникальных IMDb ID. Первые названия соответственно «Гарри Поттер и философский камень» и «Harry Potter and the Philosopher's Stone». Серверный маршрут доступен; встроенные три коллекции дополнительно работают без него. Секреты в исходники и отчёт не добавлялись.
