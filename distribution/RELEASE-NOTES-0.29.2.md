# Качалка 0.29.2

- Одна кнопка в настройках проводит через обновление: «Проверить обновления» → «Скачать» → «Обновить». Загрузка вручную не перезапускает приложение; установить можно следующим нажатием. Описание изменений доступно отдельной ссылкой.
- Повторное нажатие фильтра закрывает его меню. Исправлено для подборки, жанра, страны, рейтинга, года, порядка и минимального качества.
- Качество обозначается текстом на обложке: «4K», «Full HD», «HD Ready», «Экранка» или «SD». Пометка экранки применяется только к экранным записям; неизвестное качество не угадывается.
- Весь рекомендованный баннер открывает карточку фильма или сериала, включая фон. Доступно управление с клавиатуры.
- При первом запуске действует тёмная тема. Выбор светлой темы сохраняется после обновления.
- После установки и выбора папки приложение предлагает настроить брандмауэр и запуск вместе с Windows. В выбранной папке создаётся Ka4alka.
- Исключение брандмауэра добавляется по нажатию отдельной кнопки и запросу Windows на права администратора: только входящие TCP/UDP для Качалки в частных сетях. Доступно повторно в настройках.
- Автозапуск включается в настройках и действует для текущего пользователя. Его можно выключить; при удалении приложения запись удаляется.

Сохраняются очередь загрузок, выбранная папка, тема и настройки. Обновление проверяет подпись и скачивает изменённые компоненты.
