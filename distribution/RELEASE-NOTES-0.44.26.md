# Качалка 0.44.26

- Поиск в Windows занимает всю ширину страницы; действия находятся отдельной строкой. В невысоких окнах сохраняется компактная компоновка.
- В macOS нативная строка поиска расширяется вместе с окном вместо прежнего ограничения в 420 пикселей.
- Баннеры фильмов, сериалов, игр и «Актуального» в Windows занимают всю ширину контента. Текст и сетки карточек сохраняют удобные отступы.
- Изменение размеров окна не пересоздаёт карточки и не добавляет запросов к источникам.

Обновление сайта для этих изменений не требуется.
