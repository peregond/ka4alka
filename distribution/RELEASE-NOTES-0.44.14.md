# Качалка 0.44.14 — нативный поиск Mac

- Название страницы теперь выводится как штатный заголовок окна. Убрана стеклянная плашка, из-за которой обычный текст выглядел как кнопка.
- Поиск перенесён из содержимого страницы в системный toolbar. На macOS 15 и новее используется SwiftUI searchable с программным фокусом; на macOS 14 сохранён нативный NSSearchField в toolbar. Сохранены поиск по Return, очистка без запроса и переключение между фильмами и играми.
- Кнопка бокового меню использует один системный стиль и размер при открытой и скрытой панели. Сохранены системное меню и управление окном.

Единый выпуск для Windows x64, Mac Apple Silicon и Intel. Перед публикацией проверяются реальные окна, поиск, переключение меню и обновление с 0.44.13 с сохранением настроек и использованием неизменившихся компонентов.
