# Качалка 0.40.15

## Карточки фильмов и сериалов из поиска IMDb

Поиск по английскому названию находит фильмы и сериалы, которых нет в русском каталоге. Их карточки получают описания, жанры, страну и участников: сериалы — из TheTVDB, фильмы — из TMDB. Для сериалов предусмотрен запасной источник TVmaze.

Исправлено получение актёров из TheTVDB: сокращённый ответ больше не используется. Основное переведённое название имеет приоритет перед псевдонимом.

Карточку IMDb можно открыть из очереди загрузок. Рядом с годом сериала отображаются сезон и серия, если они указаны в названии раздачи.

## Сохранены улучшения 0.40.14

В пакет входит полный проверенный текстовый каталог. Имеющиеся описания, оценки и имена участников доступны локально; изображения загружаются отдельно. Общая библиотека пополняется ежедневно, приложение обновляет локальную копию в фоне.

Исправлена пауза magnet-загрузки при нехватке места: получение списка файлов не запускает передачу поверх установленной паузы.

## Обновление

Установщик `Kachalka-Setup-0.40.15.exe` устанавливается поверх существующей версии. Настройки, сохранённое и очередь загрузок сохраняются. Неизменившиеся компоненты при автоматическом обновлении повторно не скачиваются.
