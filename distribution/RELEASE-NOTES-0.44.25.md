# Качалка 0.44.25

- Под фотографией актёра теперь показывается имя персонажа из текущего фильма или сериала, если источник его передаёт. Неизвестные роли сохраняют подпись «В ролях» / Cast. Профессии режиссёров и других участников не меняются.
- Роли поступают из TMDB, TheTVDB и TVmaze. Актёр сопоставляется по точному имени или оригинальному имени; похожая фамилия или позиция в списке не используются. Один актёр с несколькими персонажами сохраняет одну карточку.
- На Windows фотографии участников занимают ширину своей ячейки и сохраняют пропорцию 4:5, как на Mac. Длинное имя персонажа доступно в подсказке.
- Игры на обеих платформах используют вертикальные постеры Steam 600×900 с той же пропорцией 2:3, что и фильмы. Сетки, подборки, сохранённое и загрузочные каркасы сохраняют одинаковый формат. При отсутствии постера прежняя горизонтальная обложка целиком вписывается в рамку; широкий баннер игры остаётся отдельным изображением.
- Дополнительные роли загружаются после основных сведений, кэшируются и не требуют отдельного запроса для каждого актёра. Ошибка дополнительного источника не закрывает карточку и не удаляет участников.

Имена персонажей показываются в форме, которую передаёт источник; русский ответ может содержать английское имя персонажа. Для новых полей требуется публикация соответствующего API сайта из этого же исходного коммита.
