# Качалка 0.44.2 — большое обновление интерфейса Mac

Версия для Mac переработана целиком и по структуре страниц ближе к Windows, оставаясь в стилистике macOS: единые отступы, размеры, радиусы и шрифты, адаптивные цвета для светлой и тёмной темы, оформление Liquid Glass на macOS 26 и новее с запасным вариантом для macOS 14 и 15.

Каталог, баннеры, карточки и «Сохранённое» получили рейтинги Кинопоиска и IMDb, жанры и страну, фильтры по качеству и стране, отдельные полки Featured с новостями и наградами по годам, а также игровую страницу с вертикальными обложками. Страница фильма показывает оригинальное название, жанры, разрешения, озвучку и качество релизов. Загрузки: сводные плитки, сортировка, диагностика причин остановки, файлы раздачи и значок на Dock с числом активных загрузок.

Исправлены ошибки: очередь загрузок больше не пропадает при неполных данных, состояние страниц не залипает при быстрой смене разделов, при падении движок перезапускается автоматически, а обложки загружаются быстрее и не повторяют неудачные запросы. Настройки: тема оформления (системная, светлая, тёмная), уведомления с проверкой и тестовым сообщением, понятные ошибки обновления с автоматическим возвратом прежней версии. Добавлены горячие клавиши разделов, поддержка VoiceOver, увеличенного текста, «Уменьшить движение» и «Уменьшить прозрачность».

Выпуск содержит Windows x64, Mac Apple Silicon и Intel с единым номером версии. Поведение Windows сохранено; проверяется обновление с 0.44.1.
