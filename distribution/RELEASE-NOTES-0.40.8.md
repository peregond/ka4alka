# Качалка 0.40.8

Загрузки там, где трекеры заблокированы.

- **Torrent-файлы двумя путями.** Файл раздачи NNM-Club, MegaPeer, BigFanGroup или Nyaa запрашивается одновременно напрямую и через сайт «Ка4алка Онл@йн»; используется первый ответ, который действительно является torrent-файлом. Страница блокировки провайдера или зависшее соединение больше не мешают добавить раздачу, а там, где трекер открывается, задержки нет.
- **Россия и Беларусь.** Хостинг сайта не открывается из этих стран. Если сайт не ответил, карточка фильма или сериала ищет раздачи через отдельного посредника, и torrent-файлы приходят через него же. Список посредников приложение читает с GitHub, который там доступен, и обновляет без выпуска новой версии. Массовые проверки качества для постеров каталога посредника не используют.
- **RuTracker в России.** Раздачи RuTracker из Knaben получают собственные трекеры RuTracker, местный ретрекер провайдера и публичные трекеры. Прежде в такой ссылке был один трекер, который из России не отвечает, и загрузка зависала на получении списка файлов.
- **Честное состояние источников.** Заблокированные NNM-Club и MegaPeer показываются недоступными, а не источниками без раздач.
- **Загрузки.** Рядом с названием фильма виден год выпуска. Плашки состояния снова скруглённые, длинный статус сокращается многоточием, а вместо «сиды» и «пиры» написано «отдают» и «качают».
- **Окно.** Диалоги приложения больше не появляются отдельной кнопкой на панели задач: на Windows 10 свёрнутое окно с открытым диалогом не разворачивалось щелчком по значку.
- **BigFanGroup на сайте.** Сайт тоже ищет раздачи BigFanGroup, приложение принимает их из онлайн-индекса.
- **Изменения 0.40.7**, которая отдельно не публиковалась: баннеры показывают размытый фон из постера, пока загружается широкий фон TMDB, а без постера — встроенный градиент.

Обновление сохраняет настройки, сохранённое и очередь загрузок. Неизменившиеся компоненты используются повторно.
