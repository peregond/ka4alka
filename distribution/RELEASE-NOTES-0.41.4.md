# Качалка 0.41.4

- Главная, баннеры и подборки показывают названия после получения доступного варианта загрузки. Проверка идёт в фоне с ограничением параллельных запросов; карточки появляются постепенно. Недоступный источник не считается доказательством отсутствия раздач во всём интернете.
- По правой кнопке на обложке или баннере можно скрыть фильм, сериал либо его жанр. Выбор сохраняется на этом компьютере. Раздел «Скрытые названия и жанры» в настройках позволяет вернуть скрытое; поиск, сохранённое и существующие загрузки остаются доступными.
- Чтение сохранённых результатов проверки вынесено из отрисовки карточек. Обновления главной объединяются, а список скрытых названий отображается порциями с поиском.

Публичная проверка 12 октября: 80 стартовых карточек, у трёх фильмов API вернул пустой список. Дополнительно проверены 28 текущих популярных названий: 21 ответ содержал раздачи, семь идентификаторов отсутствовали в онлайн-индексе (404). Такие ответы не подтверждают отсутствие раздач в других источниках. Наличие ссылки также не гарантирует доступность участников раздачи.
