# Качалка 0.29.0

Новый интерфейс в сине-фиолетовом стиле: кинематографичные баннеры на главной, ряды «Популярное» и «Новые фильмы» / «Новые сериалы», тёмные карточки с обложками и компактная боковая навигация. Подборка популярного загружается из каталога; если источник временно недоступен, показываются рекомендации из уже загруженных фильмов.

На широком окне фильтры находятся справа. На небольших экранах они переходят над результатами и остаются доступны при масштабировании Windows. Поиск сохраняется в карточках фильмов, сериалов и в загрузках. Пагинация и сохранённое продолжают работать.

Тёмная тема включена по умолчанию; светлая использует светлые поверхности и тот же сине-фиолетовый акцент. Обновлены очередь загрузок, список файлов и настройки. Обе кнопки удаления остаются рядом с управлением загрузкой, а название при наведении остаётся обычным текстом.

Оценки и пометки качества берутся из реальных данных. HD Ready, Full HD и 4K показываются на карточке, когда соответствующая раздача уже найдена; неизвестное качество не выдаётся за 4K или HDR. Плохое качество скрывается по умолчанию.

Интерфейс остаётся нативным WPF: используются лёгкие градиенты и кэш обложек, без тяжёлого размытия и встроенного браузера. Виртуализация очереди сохранена. Исправлена потеря быстрых движений колёсиком при отключённых анимациях Windows.

Установка и подписанное обновление сохраняют настройки и очередь. Обновление с GitHub скачивает только изменившиеся компоненты.
