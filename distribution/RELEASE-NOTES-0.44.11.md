# Качалка 0.44.11 — системные кнопки окна Mac

- Исправлено исчезновение системного светофора на Mac: кнопки закрытия, сворачивания и изменения размера окна остаются доступными. Панель действий страницы по-прежнему появляется при прокрутке.
- Удалено принудительное скрытие нативного toolbar, затрагивавшее системную область окна.
- Автоматическая проверка теперь контролирует видимость и доступность всех трёх кнопок на разных страницах, размерах окна, темах и языках, а отдельный сценарий закрывает приложение настоящей красной кнопкой.

Единый выпуск для Windows x64, Mac Apple Silicon и Intel. Проверяется переход с 0.44.10 с сохранением настроек и повторным использованием неизменившихся компонентов.
