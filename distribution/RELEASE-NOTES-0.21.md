# Качалка 0.21.0

- Исправлены переходы по каталогу: ссылка `rel=next` в заголовке страницы источника теперь учитывается. Доступно до 250 страниц по 40 карточек.
- Исправлено разбиение 60 карточек источника на страницы по 40: фильмы между страницами больше не пропускаются.
- В приложение и серверный стартовый каталог включены 3600 настоящих фильмов и 600 сериалов. Сохранённый каталог доступен постранично при недоступности источника и онлайн-индекса.
- Подборка, жанр, страна, рейтинг, год и порядок перенесены в верхнюю строку рядом с «Все» и «Сохранённое». Фильтры оформлены такими же кнопками с выпадающими меню; заголовок «Настроить подборку» убран.
- Верхние фильтры доступны в небольших окнах, а каталог использует всю ширину.

Установщик: `Kachalka-Setup-0.21.0.exe`. Обновление из предыдущей версии доступно в «Настройки → Проверить обновления». Сохранённое и пользовательские данные сохраняются при обновлении.
