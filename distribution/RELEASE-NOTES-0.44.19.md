# Качалка 0.44.19

- Кнопка «Другие части» открывает фильмы франшизы прямо под актёрами, без перехода на другую страницу. Список загружается по нажатию и располагается в порядке выхода; текущий фильм исключён.
- Звёздные войны, Гарри Поттер и Аватар доступны сразу из проверенного встроенного списка TMDB. Другие коллекции загружаются с сервера по запросу.
- Лучшие работы участника показываются одним рядом. «Ещё» раскрывает остальные работы внутри страницы. При изменении ширины окна число карточек в первом ряду пересчитывается.
- Во время загрузки фильмографии показываются такие же заглушки постеров, как в каталоге. На Windows рейтинг IMDb используется, когда отсутствует Кинопоиск; источники оценок на карточках сохраняют свои названия.
