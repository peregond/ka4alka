# Совмещение Mac polish с исправлениями озвучки

Интеграционная ветка: `claude/quirky-hopper-1vlmj6`.

Коммит `1419ba0` совмещает `claude/mac-polish` на `38161eb` с опубликованной версией 0.44.3 (`20f1b3e`). Коммит `b3b5244` дополнительно включает свежий `3205e60` из ветки Claude и проверку реальных размеров SwiftUI-меню. Ветка `claude/mac-polish` и `main` не изменялись. Нового выпуска из интеграционного коммита не запускали. Версию 0.44.3 и её опубликованные файлы заменять нельзя: для следующего выпуска нужен новый номер.

При продолжении работы в `claude/mac-polish` нужно объединить интеграционную ветку обычным merge. Это сохранит обновляемые сервером правила озвучки, распознавание дубляжа, исправление обновления списка раздач Windows и единое меню озвучки на двух платформах.

Разрешены два конфликта:

- `desktop-host/DesktopEngine.cs`: сохранены обновление правил озвучки из 0.44.2 и новые поля/счётчики источников из Mac polish.
- `macos/Sources/Ka4alka/DetailView.swift`: сохранена новая структура страницы Claude; единое меню перенесено в `DetailReleases.swift`, куда теперь вынесены фильтры.

В меню «Озвучка»: «Все», доступные «Дубляж»/«Оригинал», опциональное подменю остальных типов, затем студии. Тип и студия совмещаются, каждый параметр сбрасывается отдельно. Для игр сохранён выбор группы сборки. Рекомендация не закрепляется за конкретной студией.

В `PlatformTests.swift` добавлены проверки совместного выбора/независимого сброса, доступных типов и групп сборки игр. Сортировка загрузок приведена к общему меню-кнопке. Получено также исправление Claude `3205e60`: служебная ячейка pop-up высотой 15 pt не равна нарисованной SwiftUI кнопке. Дополнительно проверяются реальные геометрические области меню: не менее 24 pt, без выхода за ширину окна. Измерения включаются только в тестах; проверка собственной ширины нативных контролов сохранена. Значения «Дубляж» и «Оригинал» отмечены в проверке локализации как ключи протокола общего движка; при показе они переводятся через `tr(value)`.

Проверки этого совмещения:

- `dotnet build desktop-host/Kachalka.DesktopHost.csproj -c Release`
- `dotnet run --project desktop-core-tests/Kachalka.DesktopCoreTests.csproj -c Release`
- `python3 scripts/test-desktop-ipc.py <dotnet> desktop-host/bin/Release/net10.0/Kachalka.Engine.dll`
- GitHub Actions: `Verify native macOS application`, `Verify shared Windows and Mac engine`, `Verify catalog identity and incremental card updates`.

Перед выпуском нужно дождаться результатов именно для интеграционного исходного кода. Зелёные проверки отдельной ветки Claude или опубликованной 0.44.3 не заменяют эту проверку.
