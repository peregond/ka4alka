# Качалка 0.28.1

Тёмная тема теперь включена по умолчанию и первой показана в настройках. Светлую можно включить вручную. Ранее сохранённый выбор темы сохраняется при обновлении и перезапуске.

При первом запуске приложение спрашивает, куда скачивать файлы, создаёт в выбранном месте папку `Ka4alka` и сохраняет её путь. При повторном выборе существующей папки `Ka4alka` она используется без создания вложенной копии. Папку можно поменять в настройках; уже добавленные загрузки сохраняют свой прежний путь.

Для magnet-раздач The Pirate Bay добавлены резервные HTTPS- и UDP-трекеры. Они опрашиваются независимо: зависший UDP-адрес больше не задерживает остальные способы найти участников. Это работает и для ранее добавленных раздач при их возобновлении; выбранная раздача и папка файлов сохраняются. В «Подробнее» видны подключённые участники и причина ожидания; устаревшее число сидов в поиске не выдаётся за доступные подключения.

Проверки: сборка, интерфейс и установка Windows, подписанное обновление с опубликованной 0.28.0 с сохранением настроек. Обновление скачивает только изменившиеся компоненты.
