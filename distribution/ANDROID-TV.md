# Качалка для Android TV

Приложение на Kotlin и Jetpack Compose в Material 3. Интерфейс повторяет версию для Mac: тёмная тема, мятный акцент, баннер сверху с автосменой раз в 8 секунд, подборки, карточки с оценками. Поддерживаются Android TV 6.0 и новее (arm64, arm 32 бит, x86_64).

## Что умеет

- Каталог фильмов и сериалов из общей библиотеки (ту же читают Windows и Mac), поиск по русским и английским названиям, жанры, «Сохранённое».
- Раздачи ищутся на RuTracker и The Pirate Bay. Рекомендуемая выбирается по качеству, русскому звуку и числу раздающих.
- **Просмотр во время скачивания.** Кнопка «Смотреть» добавляет раздачу в очередь и сразу включает видео. Нужные части файла скачиваются в первую очередь, перемотка работает: плеер просит нужное место, торрент переставляет приоритеты.
- Загрузки: пауза, продолжение, удаление с файлами или без, выбор накопителя (память устройства, USB, SD), лимиты скорости. Очередь продолжается после перезапуска.
- **Обновление из приложения.** «Настройки → Обновление приложения». Подписанное описание версии скачивается из релиза `android-tv`, проверяются подпись (ключ тот же, что у Windows и Mac), размер и SHA-256, затем файл передаётся системному установщику. При первом обновлении Android попросит разрешить Качалке устанавливать приложения.

## Первая установка

Скачай `Kachalka-AndroidTV-<версия>.apk` из релиза [android-tv](https://github.com/peregond/ka4alka/releases/tag/android-tv) и поставь любым способом: через Downloader на телевизоре, `adb install` или флешку. Дальше приложение обновляет себя.

## Устройство репозитория

- `android/core` — логика без Android: библиотека, поиск, раздачи, торрент-движок (libtorrent4j), локальный потоковый сервер, проверка обновлений. Тестируется на обычной JVM: `cd android && gradle :core:test :core:torrentTest`. Тест `TorrentStreamingTest` поднимает настоящего раздающего и играет файл по частям.
- `android/app` — интерфейс, плеер (Media3), служба загрузок, установщик. Собирается на CI (`.github/workflows/android.yml`).
- `scripts/android-release.py` — подпись APK и описания версии.

## Выпуск

Запусти workflow **Android TV app** вручную: `version` (x.y.z), `publish` = включено, `notes` — одно-два предложения для окна обновления. Сборка подписывается воспроизводимым сертификатом, построенным из ключа обновлений (секрет `KACHALKA_UPDATE_SIGNING_KEY_PEM`), поэтому отдельный keystore не нужен и подпись не меняется между версиями. Файл `android-latest.json` переключается последним, после проверки загруженного APK.

Номер версии Android связан с кодом версии: `x.y.z` → `x·1 000 000 + y·1 000 + z`.

## Что не входит в первую версию

Нет телеметрии, уведомлений о сериях и связи с Windows-компьютерами по сети. Возможность «смотреть во время скачивания» позже можно добавить в Windows и Mac в тестовом виде: потоковый сервер и работа с приоритетами частей устроены независимо от интерфейса.
