# Качалка 0.37.0

Каталог, поиск, загрузки и настройки получили согласованные цвета, типографику и состояния кнопок. Тёмная тема остаётся основной, светлая сохраняет контраст. Карточки показывают до двух строк названия, качество на постере и компактные сведения; кнопки загрузок и поле поиска стали аккуратнее. Поиск открывается сочетанием Ctrl+K или Ctrl+F.

- Постеры загружаются для видимой области и ближайшего ряда. Ушедшие с экрана запросы отменяются; работа с диском и декодирование идут в фоне. Баннеры используют ту же очередь, количество одновременных загрузок и размер кэша ограничены.
- Возврат из фильма, участника, настроек или загрузок сохраняет запрос, страницу, фильтры и положение конкретной карточки. Изменение ширины окна и асинхронное появление данных не сбрасывают позицию. Повторный выбор текущего раздела и новый поиск начинают просмотр сверху.
- Выбранные фильтры показаны отдельными метками: их можно снять по одному или сбросить сразу. В узком окне метки прокручиваются, кнопка сброса остаётся доступной. Поисковый запрос и настройка скрытия плохого качества сохраняются.
- Раздачи показывают, когда данные действительно получены от источника или индекса. Сохранённые строки сохраняют свою дату; отсутствие даты не маскируется. Русская озвучка выделена, сведения об участниках из поиска сопровождаются пояснением о проверке при скачивании.
- «Сообщить об ошибке» открывает очищенный редактируемый отчёт, описание и шаги воспроизведения. Заполненная форма GitHub открывается только по нажатию. Для большого отчёта есть копирование и сохранение; личные пути, ссылки magnet и ключи доступа скрываются. Чтение логов выполняется в фоне.
- Удаление файлов обрабатывает атрибут «только чтение» и кратковременную блокировку другой программой. Если файл остаётся занят, задача сохраняется для повтора, а причина и этап операции записываются в диагностику. Другие файлы и исходный `.torrent` сохраняются.

Скачайте `Kachalka-Setup-0.37.0.exe` или обновитесь в приложении. Подписанное обновление с 0.36 сохраняет настройки, сохранённое и очередь. Неизменившиеся компоненты используются повторно. Диагностика загрузок, уведомления Windows, запас места, восстановление соединений и ограниченный автоматически очищаемый кэш сохранены.
