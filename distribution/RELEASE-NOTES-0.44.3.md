# Качалка 0.44.3 — единое меню озвучки

В карточках фильмов и сериалов тип озвучки и студия теперь выбираются в одном меню «Озвучка». Вверху находятся «Все», «Дубляж» и «Оригинал», ниже — студии. Многоголосая, двухголосая, одноголосая озвучка и неизвестный тип доступны в подменю «Другие типы».

Тип и студия совмещаются: можно выбрать «Дубляж + Flarrow Films» и сбросить каждый параметр отдельно. Кнопка показывает активный выбор. Обновление доступно на Windows и Mac, с русским и английским интерфейсом. В разделе игр Mac вместо фильтра озвучки показывается фильтр группы сборки.
