# Качалка 0.40.18

Новый бирюзово-зелёный знак @ объединяет оформление приложения и веб-каталога. В интерфейсе логотип имеет прозрачный фон. Иконки обновлены для EXE приложения и обновлятора, окон, уведомлений Windows, ярлыков, установки и удаления программы. Для разных масштабов Windows подготовлены размеры от 16 до 256 пикселей.

Включены все изменения 0.40.17: окно занимает всю высоту, развёрнутое окно корректно заполняет рабочую область, а страница актёра и каталог сохраняют стабильную вёрстку при изменении размера окна.

Настройки и очередь загрузок сохраняются. Обновление использует существующий механизм проверки подписи и скачивания изменённых компонентов.
