# Описания названий, которых нет в русском каталоге

Поиск по английскому названию находит через IMDb сериалы и фильмы, которых нет в каталоге Zona. Такая карточка раньше была пустой. Теперь при открытии приложение спрашивает сайт `GET /api/title?imdb=tt…&section=series|movies`, а сайт сам выбирает источник:

| Раздел | Источник | Секрет на сайте |
| --- | --- | --- |
| Сериалы | [TheTVDB](https://www.thetvdb.com/) API v4 | `TVDB_API_KEY` |
| Фильмы | [TMDB](https://www.themoviedb.org/) | `TMDB_READ_TOKEN` (тот же, что для широких фонов) |

Если секрета нет, сайт отвечает 503 только для своего раздела; приложение не считает это сбоем сайта и не откладывает остальные запросы. Для сериалов запасным источником служит TVmaze (запрос из приложения, без ключа).

## Подключение TheTVDB

1. Ключ выдан на проект малого размера (до 50 тыс. в год); такая лицензия не требует PIN подписчика у каждого пользователя.
2. Добавить ключ секретом **`TVDB_API_KEY`** в среду опубликованного сайта. Не записывать его в исходники, `.openai/hosting.json`, настройки пользователей или приложение.
3. Опубликовать `web-index/`. Проверить `/api/title?imdb=tt8910922&section=series`: ответ содержит `item` с `source: "TheTVDB"`, русским или английским `overview`, жанрами и актёрами.
4. Лицензия требует указание «Metadata provided by TheTVDB» со ссылкой на сайт: оно добавлено в настройки приложения (раздел «Каталог»).

## Как это работает

- Сервер принимает только `tt` + 5–10 цифр и один из двух разделов; названия и адреса от клиента в источники не уходят.
- TheTVDB: вход `POST /login` с ключом, сеанс хранится в памяти сервера 25 дней и обновляется при отказе (401). Поиск `GET /search/remoteid/{imdb}` принимается только при ровно одном сериале. Текст и актёры берутся из `GET /series/{id}/extended?meta=translations`: `short=true` исключает актёров. Русский перевод имеет приоритет перед английским; основное название имеет приоритет перед псевдонимом.
- TMDB: `find/{imdb}` и `movie/{id}?language=ru-RU&append_to_response=credits`; нужен ровно один фильм.
- Запросы идут с `redirect: "manual"` и ограничением размера ответа в 1–2 МБ; тело ответа источника не попадает в сообщения об ошибках.
- Совпадения кэшируются на неделю, отсутствие — на шесть часов, сбой — на минуту. Параллельные одинаковые запросы объединяются.
- Приложение принимает ответ только для IMDb-идентификатора и раздела своей карточки, жанры и страну переводит на русский (`native/TitleMetadata.cs`).

## Перед релизом приложения

Секреты среды Codex и секреты опубликованного сайта — разные настройки. В **серверной среде существующего сайта** должны быть `TVDB_API_KEY` и `TMDB_READ_TOKEN`. Для второго нужен **API Read Access Token** из TMDB → Settings → API, используемый в заголовке Bearer. Значения не входят в архив исходников и не должны попадать в приложение или GitHub.

1. Обновить исходники существующего сайта из `web-index/`, сохранив базу и привязку `DB`, и подключить серверные секреты.
2. Опубликовать сайт. Обе ссылки должны отвечать 200 с непустыми `overview`, `actors`, `genres` и правильными `imdbId`, `section`, `source`, `sourceId`:
   - `/api/title?imdb=tt8910922&section=series` — TheTVDB, 375892.
   - `/api/title?imdb=tt1160419&section=movies` — TMDB, 438631.
3. На Windows запустить `pwsh -File tests/PublishedSiteProbe.ps1`. Workflow подготовки релиза выполняет эту проверку до сборки подписанного пакета; 404, 503 и пустые описания останавливают публикацию.
4. Проверить C# отдельно: `dotnet run --project tests/Kachalka.Tests.csproj -c Release -- --imdb-suggestions-only`. Workflow Windows запускает этот тест, фикстуры сайта и TypeScript, не используя рабочие ключи.

Пакет этой ветки готовится как 0.40.15 с сохранением исправлений из ветки 0.40.14. Проверяется переход с последней опубликованной 0.40.13. Существующие релизы не перезаписывать.

Опубликованный сайт проверен 11 октября 2026 года: оба маршрута отвечают 200, Solar Opposites — 452 символа описания / 12 актёров / 3 жанра, Dune — 568 / 12 / 2. Это проверка серверных секретов сайта; состояние отдельного секрета среды Codex на неё не влияет.
