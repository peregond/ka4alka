# Качалка 0.44.5 — боковая панель Mac

На Mac «Загрузки» и «Настройки» перенесены вниз боковой панели, как в версии для Windows. Это обычные кнопки вне списка разделов: нажатие на «Настройки» снова срабатывает при каждом щелчке, число активных загрузок показывается рядом с «Загрузками».

Выпуск содержит Windows x64, Mac Apple Silicon и Intel с единым номером версии; обновление проверяется с 0.44.4.
