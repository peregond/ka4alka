# Качалка 0.33.0

Фильтры фильмов и сериалов перенесены из правой колонки под строку поиска. Они расположены в одной компактной строке; в узком окне доступны стрелки прокрутки. Каталог использует освободившуюся ширину.

- Скрытие плохого качества и выбор разрешения объединены в одной кнопке «Качество».
- Можно показать фильмы с доступными раздачами 4K, Full HD или HD Ready. Если у фильма есть несколько вариантов разрешения, он подходит каждому из них.
- Качество проверяется для текущей страницы; результаты сохраняются в кэше, ненужные запросы отменяются при переходе на другую страницу.
- Сохраняются страницы участников, автоматическая очистка кэша и лимит 1 ГБ.

Скачайте `Kachalka-Setup-0.33.0.exe` или `Kachalka-win-x64.zip`. Подписанное обновление с 0.32 сохраняет настройки, избранное и очередь загрузок.
