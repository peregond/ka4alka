0.41 улучшает отзывчивость карточек и скорость поиска раздач на сервере.

- Частичные ответы источников обновляют список раздач, сохраняя баннер, постер и блок актёров. Несколько быстрых ответов объединяются в обновление с интервалом 80 мс; ввод пользователя имеет приоритет.
- Изменение статуса источника без новых раздач обновляет индикатор и состояние источников, без повторной обработки списка и полной пересборки карточки.
- Обновления описания и раздач используют общую очередь. Открытые фильтры и меню сохраняются до завершения выбора.
- На сервере поиск по русскому названию начинается параллельно с загрузкой метаданных. Поиск по оригинальному названию сохранён. Два запроса RuTor выполняются параллельно.
- Одинаковые одновременные серверные поиски используют один запрос к источникам. Полезный ответ сохраняется на 30 секунд, кэш ограничен 64 записями; ошибки и пустые результаты можно проверить повторно сразу.
- Сохранены фильтры студий и типов озвучки, Telegram-новости и чат поддержки.

Проверки включают серию из 32 обновлений карточки с сохранением баннера, объединение 32 одинаковых серверных поисков, поведение кэша после ошибок и истечения срока, начало русскоязычного поиска до получения метаданных, сборку сервера и обновление Windows с 0.40.21.

Серверные изменения находятся в web-index. Для действующей публикации Sites требуется обновить её исходники; приложение совместимо и с предыдущей версией API. Скорость ответов внешних сайтов зависит от сети.
