# Качалка 0.44.27

- В macOS кнопка загрузки обновления называется «Скачать» / Download. После подготовки обновления остаётся «Обновить» / Update.
- Во время загрузки прогресс заполняет саму кнопку двумя оттенками зелёного, с процентом внутри. Отдельная шкала и повторяющийся статус под кнопкой убраны; ошибки остаются видимыми. При неизвестном размере внутри кнопки показывается индикатор ожидания.
- Баннеры внутри карточек фильмов, сериалов и игр Mac занимают всю ширину контента, как в общих разделах. Текст, постеры и кнопки сохраняют отступы, описание и раздачи — удобную ширину колонки.

Windows выпущен с тем же номером версии. Для этих изменений обновлять сайт не требуется.
