# Качалка 0.44.27

В macOS кнопка загрузки новой версии теперь называется «Скачать» / Download вместо «Скачать обновление» / Download update. Короткая подпись используется в боковом меню и настройках. После подготовки обновления остаётся кнопка «Обновить» / Update.

Windows выпущен с тем же номером версии; короткая подпись «Скачать» уже использовалась в его настройках.
