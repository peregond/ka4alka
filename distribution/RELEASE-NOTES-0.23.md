# Качалка 0.23.0

- Общий поиск по фильмам и сериалам: запрос запускается кнопкой «Поиск» или Enter. В результатах доступны «Все», «Фильмы» и «Сериалы» без повторного поиска; результаты разбиты на страницы.
- При возврате из загрузок сохраняются запрос и выбранный тип. Повторное нажатие текущей вкладки каталога очищает поиск и фильтры.
- Заметная анимированная полоса сообщает о поиске, загрузке каталога и поиске раздач.
- Готовое фоновое обновление показывает кнопку «Обновить» над «Загрузками» в левом меню. Мягкая пульсация учитывает системное отключение анимации; кнопка устанавливает пакет и перезапускает приложение.
- Компактные строки загрузок и общее управление: начать/остановить незавершённые загрузки, запустить/остановить завершённые раздачи.
- Общие лимиты загрузки и отдачи в КБ/с применяются сразу и сохраняются; 0 означает отсутствие ограничения.
- «Подробнее» показывает список файлов раздачи, прогресс каждой серии и число готовых файлов. Список сохраняется при перезапуске; для magnet он появляется после получения метаданных.
- «Убрать» сохраняет файлы. «Удалить файлы» с подтверждением удаляет только файлы выбранной задачи и убирает её из очереди; другие файлы в папке остаются.

Обновление через «Настройки → Проверить обновления». С 0.22.0 скачиваются только изменившиеся компоненты. Новая установка: `Kachalka-Setup-0.23.0.exe`.
