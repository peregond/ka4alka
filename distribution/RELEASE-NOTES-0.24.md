# Качалка 0.24.0

- Полностью обновлена страница загрузок: больше задач помещается на экране, у строки есть обложка слева, название, состояние, прогресс, объём и скорость. Длинное название раздачи доступно отдельно от названия фильма или сериала.
- Обложка сохраняется вместе с задачей при добавлении из карточки. Для прежних задач приложение использует точное совпадение с локальным каталогом; если обложка неизвестна или совпадение неоднозначно, остаётся нейтральная заглушка.
- Пауза, продолжение, подробности и открытие папки получили понятные иконки. Серое «Удалить из загрузок» убирает задачу, сохраняя её файлы. Красное «Удалить файлы» с подтверждением удаляет скачанные и частичные файлы этой задачи.
- Массовый запуск и остановка загрузок и раздач, а также лимиты загрузки и отдачи собраны в верхнем меню управления. Лимиты сохраняются, 0 означает отсутствие ограничения.
- По умолчанию последние добавленные задачи находятся сверху. Доступны сортировки по названию, скорости, размеру и прогрессу; выбор сохраняется при перезапуске. Текущие скорости обновляются без постоянного переставления строк под курсором.
- Окно «Подробнее» оформлено в выбранной светлой или тёмной теме. В нём видны состав раздачи, готовые файлы, общий прогресс и прогресс каждой серии; поиск помогает найти нужный файл.
- Очередь, папки загрузок и настройки сохраняются при обновлении. Дата добавления восстанавливается для задач из старой очереди.
- Исправлена сборка обновлятора: служебные отладочные данные больше не меняют его при обновлениях интерфейса. При переходе с 0.23.0 этот компонент загрузится один раз.

Обновление через «Настройки → Проверить обновления» или кнопку «Обновить» после фоновой загрузки. С 0.22.0 скачиваются только изменившиеся компоненты. Новая установка: `Kachalka-Setup-0.24.0.exe`.
