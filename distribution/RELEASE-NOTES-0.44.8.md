# Качалка 0.44.8 — боковое меню Mac

Исправлено боковое меню на Mac: нажатие на раздел больше не открывает соседний (например, «Актуальное» вместо «Сериалов»). Меню собрано как обычный столбец кнопок, без прокручиваемого списка, из-за которого область нажатия сдвигалась относительно нарисованных строк. Подпись «Медиатека» убрана, разделы расположены выше, «Загрузки» и «Настройки» остаются внизу, как в версии для Windows.

Выпуск содержит Windows x64, Mac Apple Silicon и Intel с единым номером версии; обновление проверяется с 0.44.7.
