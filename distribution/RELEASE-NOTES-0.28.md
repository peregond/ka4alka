# Качалка 0.28.0

- 💩 с подсказкой «Плохое качество» у экранок и видео ниже выбранного минимума: в раздачах, на проверенных карточках каталога и в очереди загрузок.
- Сверху каталога и раздач — общий фильтр «Скрыть плохое качество». Минимум HD Ready (720p) или Full HD (1080p); настройка сохраняется. CAM/TS/Screener считаются плохими даже при заявленных 1080p/4K. Неизвестное качество остаётся видимым.
- Фильм скрывается из каталога только когда недавно проверенные доступные варианты все плохие. Наличие хорошего или неизвестного варианта сохраняет карточку. Уже добавленные загрузки остаются в очереди.
- Добавлены реальные публичные источники BigFanGroup и The Pirate Bay для фильмов и сериалов. BigFanGroup использует русские названия, правильную кодировку поиска и распознаёт анимационные сериалы в категории мультфильмов.
- Онлайн-индекс и дополнительные источники проверяются параллельно. Одна найденная экранка больше не останавливает поиск качественных альтернатив. По умолчанию раздачи с русскоязычных источников показываются первыми; сортировку можно изменить.

Проверки: распознавание плохого качества, фильтры каталога и раздач, сохранение настройки, очередь и узкие окна Windows; живые ответы новых источников для фильмов и сериалов и проверка настоящих torrent-файлов; установка и обновление с опубликованной 0.27.0 с сохранением данных.

Обновление скачивает изменившиеся компоненты. Качество определяется по сведениям раздачи: приложение не оценивает кадры видео и не помечает неизвестные варианты как плохие.
