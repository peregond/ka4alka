# Проверка опубликованной 0.44.20

Опубликована 22 октября 2026 года: https://github.com/peregond/ka4alka/releases/tag/v0.44.20

Исходный коммит приложения: `08233f1d2e19b844d48636f74bfe14080539b2f6`.

## Воспроизведение и исправление

- Публичный `/api/catalog?section=movies&q=гарри%20поттер` возвращал HTTP 200 и одну карточку: документальный фильм о съёмках 2026 года. Английский запрос `Harry Potter` возвращал 13 записей, включая основные фильмы. IMDb-подсказки принимают латинские запросы и заранее подтверждённые переводы; общая русская фраза этой франшизы к ним не относилась.
- Встроенные франшизы уже содержали точные IMDb ID и русские/английские названия восьми фильмов, но не участвовали в общем поиске. `UnifiedSearch` теперь добавляет совпадения этого локального индекса перед ожиданием источников. Туда же попадают ещё не истёкшие загруженные коллекции; дополнительных сетевых запросов нет.
- Для поиска и раздела «Другие части» используется одна фабрика карточек. Поисковые совпадения объединяются существующей проверкой идентичности фильма, сохраняющей ссылку каталога и метаданные. Поиск не подменяет язык интерфейса, категорию или год выпуска.

## Регрессионные проверки

- Новый тест сначала воспроизвёл ошибку на старом коде. С исправлением пустой профиль сразу получает все восемь IMDb-идентичностей по русскому запросу; поздний ответ с документальным фильмом не стирает эти результаты. Английский запрос находит те же восемь частей без IMDb-подсказок.
- Проверены объединение настоящей карточки каталога с франшизой без дублей, фильтр игр, выбор конкретного года, другие встроенные франшизы и уже загруженная коллекция без повторного запроса.
- Локально прошли полный `desktop-core-tests`, `catalog-text-tests`, сборки Windows и desktop-host, а также настоящий JSON IPC: русский и английский запросы нового профиля вернули восемь частей с локализованными названиями. Сборка Windows сохраняет два прежних nullable-предупреждения в FeaturedPortal и GamesSmoke (временная и итоговая сборки сообщают о них отдельно).
- Отдельный облегчённый тестовый проект сначала не собирался из-за отсутствовавшего подключения франшиз; добавлены исходник, встроенный JSON и платформенные адаптеры. Сетевой метод адаптера намеренно выбрасывает исключение: эти регрессионные тесты должны оставаться автономными. Повторный CI https://github.com/peregond/ka4alka/actions/runs/39844666860 успешно прошёл.
- Выпуск: https://github.com/peregond/ka4alka/actions/runs/39845749314 . Предыдущие запуски `39843828212` и `39844704488` отменены до упаковки: исправлены подключения облегчённого тестового проекта и локализация строк нового Mac-сценария.
- В первом релизном прогоне Linux выполнил тесты общего ядра и IPC, но установка системных зависимостей Playwright из `azure.archive.ubuntu.com` исчерпала лимит задачи. Браузерные проверки тогда не запускались. Повторены только эта задача и зависимые этапы; повторный прогон успешно прошёл. Windows, Apple Silicon и Intel прошли без повторного выполнения их успешных задач.
- macOS 27: https://github.com/peregond/ka4alka/actions/runs/39845696456 — успешно, 563 проверки, без ошибок и предупреждений. Тест настоящего экрана поиска вводит оба названия и сохраняет `search-potter-dark-ru.png` и `search-potter-light-en.png`. Русский снимок визуально подтверждён: восемь основных частей и отдельный документальный фильм.
- Производительность Windows с 2 и 4 ядрами: https://github.com/peregond/ka4alka/actions/runs/39843779912 — обе задачи успешны.
- Прогон производительности использует `6c9988d0aca13b168eb1a38d2fab632d40aa0197`. После него менялись только два файла облегчённого тестового проекта и три строки локализации тестового сценария Mac. Исходники Windows и общего поискового ядра идентичны; Mac проверяется заново на точном коммите релиза.

Изменений серверных маршрутов для этого исправления не требуется. Секреты не добавлялись в исходники и отчёт.
