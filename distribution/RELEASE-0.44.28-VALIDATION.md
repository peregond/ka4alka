Изменения мобильной страницы управления по QR-коду встроены в общую библиотеку LAN для Windows и Mac. Публичный сайт, DB, домен и настройки Railway для этого выпуска не менялись.

Исходный коммит: `0d47e689bf5f83c1fc9bfd0fb49b5cfa029d75dd`.

Мобильные Chromium и WebKit прошли русский и английский интерфейс, системные светлую/тёмную темы, обычное и запрещённое sessionStorage, ширины 320–820px. Проверены QR и ручное подключение, страницы каталога, поиск, пустые результаты и повтор, возврат с сохранением прокрутки без запроса каталога, качество/озвучка/порядок раздач, рекомендация, фильтры очереди, пауза/продолжение, отмена и подтверждение повторного скачивания, панель magnet-ссылки, тема, перезагрузка и выход. Это проверка движка WebKit с профилем iPhone, без физического устройства iOS.

Проверка телефона через HTTP: 27 сценариев. Существующие mTLS-проверки: 60. Реальная torrent-передача, запущенная через телефонный HTTP API, проверена по SHA-256. Новые данные очереди не содержат локальный путь изображения; размер берётся из реальной задачи. Восстановление удалённых файлов требует отдельного подтверждения.

Политика безопасности выпуска не менялась. WebKit блокирует собственный внутренний атрибут `text-overflow:inherit` нативного select. Тест классифицирует только этот точный диагностический образец; остальные нарушения CSP и ошибки JavaScript приводят к сбою. Параметр `report-sample` добавляется только к перехваченному ответу внутри теста. Скриншоты фикстуры снимаются Chromium: помощник снимков WebKit сам вставляет запрещённый inline-стиль. Все функциональные проверки выполняются обоими браузерами. Изображения фикстуры не выдаются за настоящий каталог и не включены в публичную галерею приложения.

На macOS 27: 78 Swift-тестов, 606 UI-проверок, 119 сочетаний экранов/размеров/тем/языков; 0 нарушений.

Intel Mac: 78 Swift-тестов, 605 UI-проверок, 119 сочетаний, 0 нарушений. Windows прошёл полный набор тестов интерфейса, установку/удаление и обновление с публичной 0.44.27: скачано 7 652 999 из 108 105 056 байт, переиспользованы 422 файла, изменены 5 компонентов.

Первый прогон подготовки остановился на тайм-ауте существующего распознавания озвучки Windows и сбое создания Intel DMG после успешной компиляции/ZIP. Повторены только неудачные задания на том же коммите; оба прошли. Частичные временные CI-артефакты сохранены с проверкой SHA-256 перед заменой полными результатами. Проверки и политика безопасности приложения не ослаблялись.
