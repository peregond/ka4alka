## Backrooms и сайт

Sites сообщил о публикации версии 13 из того же исходного коммита. Независимая публичная проверка `/api/localized-media?language=en&imdb=tt26657236&section=movies` вернула HTTP 200, id `tt26657236`, section `movies` и непустой backdrop. `/api/backdrop-image` вернул HTTP 200, декодируемый JPEG 1280×720 (78 908 байт). Секреты в клиент, отчёт и исходники не добавлялись.

В приложении русский заголовок Backrooms связан с проверенной IMDb-идентичностью; английский интерфейс сохраняет Backrooms. IMDb-ссылки «Поделиться» и ответ фонового API проверены тестами, включая отказ от изображения другой категории. Единый поиск сохраняет фильмы, сериалы и игры отдельно и не теряет остальные результаты при отказе Steam.
