# Качалка 0.44.9 — безопасность

Закрыты уязвимости в зависимостях сайта (обновлены Next.js и React), посредник для России и Беларуси теперь проверяет каждый редирект трекера до запроса и ограничивает число запросов с одного адреса, на страницы сайта добавлены защитные заголовки. Адрес потока из каталога ТВ и радио с пробелами или переводами строки больше не принимается.

Выпуск содержит Windows x64, Mac Apple Silicon и Intel с единым номером версии; обновление проверяется с 0.44.8.
