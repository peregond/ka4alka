# Качалка 0.44.9 — шапка окна Mac в тёмной теме

В тёмной теме на Mac верхняя панель окна (заголовок раздела, поиск и кнопки) больше не выделяется серой плашкой на почти чёрной странице: она берёт цвет страницы. Светлая тема не изменилась.

Выпуск содержит Windows x64, Mac Apple Silicon и Intel с единым номером версии; обновление проверяется с 0.44.8.
