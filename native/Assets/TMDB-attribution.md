# The Movie Database artwork attribution

The approved Primary short (blue) logo is sourced from TMDB's official
[Logos & Attribution](https://www.themoviedb.org/about/logos-attribution) page.

Original SVG:
https://www.themoviedb.org/assets/v4/logos/v2/blue_short-8e7b30f73a4020692ccca9c88bafe5dcb6f8a62a4c6bc55cd9ba82bb2cd95f6c.svg

`tmdb-logo.svg` is the unmodified source. `tmdb-logo.png` is a transparent
384-pixel raster rendering for WPF; it preserves the logo's proportions and
colours. The application displays it at 128 DIP in Settings → Каталог,
alongside the attribution statement.

TMDB owns its name and logo. This product uses the TMDB API but is not endorsed
or certified by TMDB.
